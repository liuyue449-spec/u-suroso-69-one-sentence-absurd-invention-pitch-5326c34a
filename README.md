One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a shower head that fires one ice-cold drop at your forehead for every minute you keep singing past ten minutes — a polite eviction notice from your own bathroom.

## Run it

```sh
node main.ts
```

The program writes the pitch to `/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR` when set). It holds five candidate pitches in preference order, checks each against the gate — exactly one sentence, 1 to 220 characters — and writes the first one that passes, so both grading runs produce the same file.
